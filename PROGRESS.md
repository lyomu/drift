## Preview APK

`drift-tennis-preview.apk` (project root) is a release build for hands-on testing. Rebuild with:

```
cd mobile
flutter build apk --release --dart-define=DRIFT_API_BASE_URL=http://<your-lan-ip>:3000
```

Three Android config fixes were needed to make a release build actually work (found by running it, not by tests):

1. **`INTERNET` permission** — Flutter's template declares it only in `android/app/src/debug/AndroidManifest.xml`, so release builds shipped without it and every API call failed silently with no logcat error. Now declared in `src/main/AndroidManifest.xml`.
2. **Cleartext HTTP** — `targetSdk` 36 blocks plain http by default. `res/xml/network_security_config.xml` allowlists only the dev hosts (10.0.2.2, localhost, the LAN IP), deliberately not a blanket `usesCleartextTraffic`. **Add your LAN IP there when it changes**, or the app fails to connect.
3. **API base URL** — was hardcoded to `10.0.2.2` (emulator-only). Now overridable at build time via `DRIFT_API_BASE_URL`, falling back to the old per-platform defaults.

The APK needs the backend (`npm run start:dev`) reachable at the baked-in address. Release is signed with the debug key (`build.gradle.kts` still has the template TODO) — fine for previews, not for distribution.
