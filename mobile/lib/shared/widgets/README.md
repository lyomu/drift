# Shared Widgets

Cross-feature reusable components — the Flutter implementation of the component inventory in `foundation/05-design-system.md` §6-7.

- `drift_hero_scaffold.dart` — full-bleed solid-colour hero background (Welcome/onboarding-style screens)
- `buttons/drift_button.dart` — primary / pill / text button variants
- `drift_card.dart` — base card wrapper
- `drift_text_field.dart` — text input wrapper
- `drift_status_badge.dart` — icon+label status badge (match/competition states)
- `drift_filter_chip.dart` — selectable filter chip

More get added as features need them (player card, match card, skill breakdown, etc. land alongside the features that first use them, starting Phase M3).
